Yeu cau
-------
- Cai 7-Zip tren Windows hoac goi 7z/p7zip tren Linux.
- Android Studio hoac Android Emulator.
- Can khoang 7 GB dung luong trong Android SDK sau khi giai nen.

1. Kiem tra va khoi phuc ZIP tren Windows
-----------------------------------------
Dat tat ca cac file .7z.001 ... .7z.008 trong cung mot thu muc.

Kiem tra checksum tung volume bang PowerShell:

  Get-Content .\sdk-repo-linux-system-images-automotive-mysystemapp-v5.volumes.sha256 | ForEach-Object {
      $parts = $_ -split '\s+', 2
      $actual = (Get-FileHash -Algorithm SHA256 $parts[1]).Hash.ToLower()
      if ($actual -ne $parts[0]) { throw "Checksum mismatch: $($parts[1])" }
  }

Mo sdk-repo-linux-system-images-automotive-mysystemapp-v5.7z.001 bang 7-Zip va chon Extract,
hoac dung command line:

  7z x sdk-repo-linux-system-images-automotive-mysystemapp-v5.7z.001

Ket qua thu duoc:

  sdk-repo-linux-system-images-automotive-mysystemapp-v5.zip

Kiem tra SHA-256 cua ZIP:

  certutil -hashfile sdk-repo-linux-system-images-automotive-mysystemapp-v5.zip SHA256

SHA-256 dung:

  ec06e9e8df8252b8fd668d10b3e7eaffe11a47391649e14ee3deee3b6231f6ae

2. Cai system-image vao Android SDK tren Windows
-------------------------------------------------
Dong Android Studio va tat tat ca emulator dang chay, sau do mo PowerShell:

  $Sdk = "$env:LOCALAPPDATA\Android\Sdk"
  $Destination = "$Sdk\system-images\android-37\android-automotive"
  New-Item -ItemType Directory -Force -Path $Destination
  Expand-Archive -Path ".\sdk-repo-linux-system-images-automotive-mysystemapp-v5.zip" `
      -DestinationPath $Destination -Force

Cau truc sau khi cai phai la:

  %LOCALAPPDATA%\Android\Sdk\system-images\android-37\android-automotive\x86_64\source.properties
  %LOCALAPPDATA%\Android\Sdk\system-images\android-37\android-automotive\x86_64\system.img
  %LOCALAPPDATA%\Android\Sdk\system-images\android-37\android-automotive\x86_64\vendor.img
  %LOCALAPPDATA%\Android\Sdk\system-images\android-37\android-automotive\x86_64\ramdisk.img

Khoi dong lai Android Studio, mo Tools > Device Manager > Create Virtual Device,
chon mot Automotive hardware profile va image "AOSP Automotive" x86_64.

3. Cai tren Linux
-----------------
  sha256sum -c sdk-repo-linux-system-images-automotive-mysystemapp-v5.volumes.sha256
  7z x sdk-repo-linux-system-images-automotive-mysystemapp-v5.7z.001
  sha256sum -c sdk-repo-linux-system-images-automotive-mysystemapp-v5.zip.sha256
  mkdir -p "$ANDROID_SDK_ROOT/system-images/android-37/android-automotive"
  unzip sdk-repo-linux-system-images-automotive-mysystemapp-v5.zip \
      -d "$ANDROID_SDK_ROOT/system-images/android-37/android-automotive"

Hoac chay truc tiep bang script run_local_avd.sh:
  setsid env ANDROID_SDK_ROOT="$HOME/Android/Sdk" WORKDIR="$HOME/.aaos-new-avd" \
      AVD_IMAGE_DIR="/path/to/extracted/x86_64" ABI=x86_64 AVD_NAME=my_car_new_avd_x86_64 \
      /path/to/run_local_avd.sh -gpu swiftshader_indirect -wipe-data -no-snapshot-load > ~/aaos_avd.log 2>&1 &
